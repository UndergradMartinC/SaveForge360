# Porting order

1. **Fable II:** finish round-trip validation with contributor-owned saves, then support reinserting both edited inner files into their original package.
2. **Midnight Club: Los Angeles:** use the same browser module interface and port the open-source reference tool's behavior into the current editor after Fable II validation.

Each further game port must identify its internal save files, preserve unedited data, validate a real or synthetic fixture, and prove a round trip before package export is enabled.
